# Attendance Calculator

A lightweight, browser-based attendance calculator that I built from scratch.

### Why I Built This
I created this tool to provide a simple, distraction-free way to calculate attendance percentages and instantly figure out:
- Your current attendance percentage.
- How many consecutive classes you need to attend to hit your target goal.
- How many classes you can safely miss without falling below the required cutoff.

### Built With
- **HTML** – For the layout and form inputs.
- **JavaScript** – For the math calculations and dynamic results.
- **Zero Dependencies** – Everything is contained within a single file.
